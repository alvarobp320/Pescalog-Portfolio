# PescaLog — visión del producto

## Resumen

PescaLog es una aplicación móvil en desarrollo cuyo objetivo es ayudar a las personas aficionadas a la pesca a organizar y consultar la información relacionada con sus salidas.

La propuesta parte de una necesidad cotidiana: conservar en un mismo lugar los datos que hacen útil cada jornada y poder volver a ellos con facilidad. El producto se encuentra en fase de construcción, por lo que esta visión describe la dirección del proyecto y no una lista de funciones ya publicadas.

## Problema que aborda

La información de una jornada puede acabar repartida entre notas, fotografías y recuerdos. Esa dispersión dificulta comparar salidas o recuperar detalles más adelante.

PescaLog plantea una experiencia móvil que permita centralizar esos registros y sentar las bases para consultar la actividad de forma ordenada.

## Para quién

Personas que practican la pesca y quieren mantener un registro personal de sus jornadas desde el teléfono. El perfil, las necesidades y los casos de uso se podrán concretar mediante pruebas con usuarios.

## Principios de experiencia

- **Rápida en el contexto de uso:** pensada para consultarse desde un móvil.
- **Clara:** priorizar la información útil y una navegación comprensible.
- **Personal:** el registro pertenece a cada usuario.
- **Evolutiva:** separar la aplicación móvil de los servicios y datos permite ampliar el producto progresivamente.

## Alcance previsto

La dirección del producto es ofrecer una base para registrar y consultar la actividad de pesca. El detalle exacto de campos, pantallas y funcionalidades está pendiente de consolidarse con la implementación y validación del producto.

Por tanto, este portfolio no atribuye a la versión actual funciones como mapas, partes meteorológicos, comunidad, estadísticas avanzadas o sincronización en producción.

## Cómo valorar el proyecto

PescaLog permite mostrar el recorrido de un producto digital desde una necesidad concreta hasta una arquitectura móvil con backend y base de datos. También abre un espacio para aprender sobre experiencia de usuario, autenticación, persistencia y despliegue de aplicaciones.
