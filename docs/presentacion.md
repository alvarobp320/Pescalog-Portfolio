# PescaLog — presentación breve

## 1. El proyecto

**PescaLog** es una app móvil en desarrollo para organizar y consultar la actividad de pesca desde el teléfono.

## 2. La necesidad

Los detalles de las jornadas pueden quedar repartidos entre notas, fotos y recuerdos. La propuesta es ofrecer un espacio personal y ordenado para conservar esa información.

## 3. La experiencia

El producto se está planteando para móvil, con una navegación sencilla y una experiencia que pueda evolucionar a partir de las necesidades de quienes pescan.

## 4. Cómo está construida

- **Móvil:** React Native y Expo.
- **Servidor:** Java y una API HTTP.
- **Datos:** PostgreSQL.
- **Sesión:** autenticación basada en JWT prevista en la arquitectura.

La app se comunica con el backend, y el backend gestiona el acceso a la base de datos.

## 5. Estado actual

La aplicación se ha iniciado en Android con Expo. La solución todavía está en desarrollo: no tiene despliegue público confirmado ni está publicada en las tiendas.

## 6. Próximos pasos

Concretar el alcance de la primera versión, completar la integración móvil-API, preparar un entorno de pruebas alojado, validar los flujos y reunir capturas reales del producto.

## Mensaje de cierre

PescaLog es un proyecto en evolución que combina diseño de producto móvil con una arquitectura cliente-servidor. El siguiente hito es convertir la base técnica en una experiencia completa, validada y lista para probar.
